# Lunaris Luxury Template

Landing page premium noir & or pour marques d’exception. Le template inclut un hero immersif, des sections modulaires (collections, expérience, atelier) et un bloc contact prêt à l’emploi, avec micro-interactions et animations dévoilées au scroll.

## Utilisation
- Ouvrez `index.html` dans votre navigateur pour prévisualiser la page.
- Personnalisez la palette et les textes dans `styles.css` et `index.html`.
- Les animations de révélation et le scroll fluide sont gérés dans `script.js`.

## Palette rapide
- Fond : noir profond `#070708`
- Or signature : `#cfa75e`
- Typographies : Playfair Display (titres) & Manrope (texte)
